# ファイルと形式

プロジェクトは、普通のファイルとして書き出すまでブラウザのストレージに残ります。このページでは、プロジェクトの保存と再度開く操作、持ち運べる `.szd` ファイル、Standard MIDI File と MIDI 2.0 クリップファイル、DAWproject、MusicXML、WAV のミックスダウンとステムを説明します。オーディオの読み込みと録音は、[オーディオの録音と解析](audio-recording-and-analysis.md)にあります。

## プロジェクトを保存して開き直す

1. **ファイル** > **別名で保存...** を開き、名前を入力して確定します。
2. 保存が終わると、プロジェクト名の隣にある未保存の変更を示すマークが消えます。以降は、**ファイル** > **保存** で同じ名前に書き込みます。
3. リロードしたあとのスタート画面には、**前回の続き**の隣に保存済みのプロジェクトが名前で並びます。プロジェクト名をクリックすると開きます。

開き直したプロジェクトは、保存したときと同じトラック、クリップ、音源、コード、ノートを持ち、同じオーディオをレンダリングします。取り消し履歴は空から始まります。名前付きリビジョンは、[オフライン利用と設定](offline-and-settings.md)で説明しています。

## `.szd` ファイル

**ファイル** > **.szdを書き出し** は、プロジェクトを持ち運べる ZIP アーカイブとしてダウンロードします。アーカイブには、プロジェクトのドキュメント、メタデータ、プロジェクトが使うオーディオ、使う SoundFont がまとめて入ります。

ファイルは、スタート画面の **.szd を読み込む...** から開きます。読み込んだプロジェクトは、書き出したものと同じトラック、音源、クリップを持ち、同じオーディオをレンダリングします。編集は通常どおり取り消せます。

## Standard MIDI File と MIDI 2.0 クリップファイル

Standard MIDI File または MIDI 2.0 クリップファイルは、スタート画面の **MIDI を読み込む...** か、**ファイル** > **MIDIを読み込み...** から読み込みます。2 つの形式は、拡張子ではなくファイルのヘッダーで判別します。プロジェクトはノートのベロシティとコントローラーの値を MIDI 1.0 の分解能で保持するため、MIDI 2.0 クリップファイルの 16 ビットのベロシティと 32 ビットのコントローラー値は、読み込み時に 7 ビットに丸められます。ノートを含む各パートがトラックになり、ドラムチャンネルにはドラムキットが割り当てられます。あとから追加したノートは、描いたトラックのチャンネルを保ちます。メロディーのノートはそのチャンネルのまま、ドラムのヒットはチャンネル 10 のままです。**リスト**タブのコードリストにある**進行を推定**は、ドラムに結果を乱されることなく、読み込んだパートを読み取ります。

- **ファイル** > **SMFを書き出し** は、拡張子 `.mid` の Standard MIDI File をダウンロードします。
- **ファイル** > **MIDI 2.0クリップファイルを書き出し** は、拡張子 `.midi2` の MIDI 2.0 クリップファイルをダウンロードします。

Standard MIDI File はオーディオを保持できません。プロジェクトにオーディオトラックがあると、**SMFを書き出し**は、まず省略される内容（オーディオトラックの名前を含む）を一覧にして、確認を待ちます。確認後のファイルには、クリップのノートが、音高とタイミングをクリップから 1 ティック以内の誤差に収めて入ります。

## DAWproject

- **ファイル** > **DAWprojectを書き出し** は、プロジェクトのドキュメントとメタデータのエントリーを持つ `.dawproject` ZIP アーカイブをダウンロードします。アーカイブには、すべてのトラックとクリップが入り、プロジェクトのオーディオは WAV ファイルとして埋め込まれ、ドラムのノートを含む MIDI ノートはチャンネル 10 のまま保たれます。
- **ファイル** > **DAWprojectを読み込み...** は、`.dawproject` ファイルを開きます。読み込むと開いているプロジェクトが置き換わります。開いているプロジェクトに未保存の変更がある場合は、破棄する前に確認します。

書き出したアーカイブを読み込むと、同じトラックとクリップが同じ位置と長さで、同じコード範囲と同じ MIDI ノートとともに復元され、オーディオトラックは聞こえる形でレンダリングされます。読み込んだプロジェクトをもう一度書き出すと、同じトラック、クリップ、ノートになります。

## MusicXML

- **ファイル** > **クリップをMusicXMLとして書き出し...** は、アクティブなクリップを、クリップのノート 1 つにつき 1 つの音高付きノートを持つ `.musicxml` の譜面として書き出します。
- **ファイル** > **クリップを圧縮MusicXML (.mxl) として書き出し...** は、同じ譜面を圧縮した `.mxl` アーカイブとして書き出します。最初のエントリーは圧縮されていない `mimetype` で、コンテナーファイルがアーカイブ内の譜面の名前を示します。
- **ファイル** > **MusicXMLを読み込み...** は、どちらの形式も開きます。読み込むと開いているプロジェクトが置き換わり、未保存の変更がある場合は、破棄する前に確認します。

読み込んだファイルでは、ノートが同じ音高、位置、長さで戻ります。

## オーディオのミックスダウンとステム

**ファイル** > **オーディオを書き出し...** は、**オーディオを書き出し**ダイアログを開きます。

- **範囲**は、プロジェクト全体か**ループ範囲**です。
- WAV の**ビット深度**には **32-bit float** があります。
- **マスターインサート、EQ、マスタリングチェーンを適用**は、マスターバスをレンダリングに含めます。チェーンをオンにすると、出力はドライのミックスと異なり、そのピークは**マスタリング**タブで設定した上限以下に収まります。チェーンの出力は、プロジェクトを保存して開き直したあとも同一です。
- **リリーステール**は、最後のクリップのあとに秒数を足します。テールが 0 でプロジェクト全体を選んでいるとき、ファイルの長さはプロジェクトの長さと一致します。
- **形式**は、WAV、**FLAC (lossless)**、**MP3 (CBR)** です。FLAC ファイルは、同じレンダリングの WAV と同じサンプルにデコードされます。MP3 ファイルは、WAV と同じ長さ（コーデックの開始遅延と終端のパディングの範囲内）、ピーク、ラウドネスを持ちます。
- **モード**は、**ミックスダウン**か**ステム**です。

**書き出し**を押します。レンダリングが終わるとダイアログにピークレベルを含むラウドネスレポートが表示され、ファイルが選んだ形式でダウンロードされます。

**ステム**モードでは、ダウンロードされるのは、トラックごとに 1 つの WAV を収めた ZIP で、各ファイルはトラック名で命名されます。ステムはミックスダウンと同じサンプルレートと長さで、各ストリップのフェーダーとパンを反映し、足し合わせるとミックスダウンになります。**最終マスターのステムを含める**と**バス / リターンのステムを含める**は別々のトグルです。どちらもオフにすると、アーカイブにはトラックごとの WAV だけが入ります。

長いプロジェクトのレンダリングは、マスタリングチェーンが一度に処理できる量を超えることがあります。その場合、ダイアログはレンダリングの前に止まり、ダウンロードは提供されず、範囲を短くするかマスターチェーンをオフにするよう案内します。
